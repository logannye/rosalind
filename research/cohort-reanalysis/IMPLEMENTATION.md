# Implementation and evidence gates

This checklist separates authored code, pure Python checks, exact-revision native
validation, and measurements. Checking an implementation item is not evidence of
passing hosted validation or completing the proposed public cohort roadmap.

## Implemented research slice

- [x] Explicit bounded member manifest with one leaf per specimen; named scope,
  compatible fields, duplicate source/scope rejection and preserved metadata.
- [x] Separate scientific comparison identity and unchanged native reuse identity;
  effective reference role plus exact byte identity, with no representation equivalence.
- [x] Native coverage adapter and Python wrapper authored over `coverage_split`;
  native normalization owns VCF/BCF coordinates and allele validation.
- [x] Metadata-only plan and strict preflight missingness refusal; partial queries
  send only covered intersections to the existing strict reader.
- [x] Checked uint64 window reducer, positive threshold screens, explicit observed
  denominators, null fraction pairs at zero, and canonical output order.
- [x] Serial lazy native streaming with batch/type/completion checks and REF checks
  on observed rows; no observed saved row means reference validation is unavailable.
- [x] Parent-state admission, capped candidates/metadata/children/output inventory,
  and cooperative native budgets with no OS-cap claim.
- [x] Separate wrapper manifest, consumed-input union rechecks, create-new staging
  publication, retained failure records, verify and scientific replay commands.
- [x] Pure Python tests for the unchanged fixture oracle, >2^53 integers, uint64
  overflow, missing/zero observations, multiallelic thresholds, compatibility,
  earlier-input mutation, no-clobber publication, verification and admission.
- [x] Synthetic diagnostic B/C/D protocol and bounded Parquet baseline authored;
  performance-only versus content-checked costs are labeled separately.

## Exact-source validation completed

- [x] Build the exact changed source revision on hosted infrastructure; record
  commit, binary hash, Rust/platform identity and dependency versions.
- [x] Pass focused native coverage adapter tests, unchanged fixture validator,
  Python wrapper checks and the full research integration tests on that artifact.
- [x] Pass relevant existing native conformance, saved-data replay and CRAM gates;
  historical passes do not certify this revision.
- [x] Confirm canonical scientific output across admitted windows/budgets,
  including member order, repeated candidates, empty queries and new ALTs.
- [x] Exercise failed native children, corrupted payloads, earlier-consumed input
  mutation, interruption, output collisions and source-free relocated replay.
- [x] Record hosted results and all failures with exact revision/binary provenance.

## G2 diagnostic decision

- [x] Run the locked multi-partition synthetic B/C/D pilot and retain every trial,
  setup cost, exact comparison, sampled process-tree memory and logical storage.
- [x] Inspect full setup-plus-query totals, one-shot outcomes and small-window
  stress behavior. Do not subtract integrity costs from only one path.
- [x] Write the observed bottleneck, mechanism, predicted effect, smallest
  falsifying experiment, result, and keep/abandon decision.
- [x] Choose a concrete useful scale and resource target from evidence, or stop
  extending this research wrapper if it has no meaningful operational advantage.

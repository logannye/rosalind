# Frozen HG002 evidence-reuse protocol

The machine protocol is [protocol-v1.json](protocol-v1.json). Its exact bytes are
bound to the build record before acquisition. Queries are generated and hashed
from reference-only probes before the oracle, native extraction, or query timings.
The full reference dictionary and all overlapping source records are preserved by
the unchanged representative preparation. Only `window-bam-sites` is executed.
Preparation also creates unused CRAM, panel, and chromosome selections; its whole
cost is disclosed. The 1,000 reference-derived probes are not truth variants.

Three hypotheses have explicit falsifiers. Exact scientific observations must
survive changed compatible requests: every one of 34 full legacy TSV columns
must agree with the independent general-CIGAR pysam oracle, and all 27 query
answers must equal expectations derived separately from that oracle. Saved-only
execution must succeed after complete relocation in a second clean job with no
raw inputs supplied. Finally, a changed Q1-consumed payload with unchanged
manifests must cause both verification and query refusal, with no successful
primary output or receipt. Missing loci and wrong REF must fail; stored zero
remains an observation. The native synthetic control explicitly covers zero.

A extracts fresh reads; B queries the existing native portable dataset; D queries
checked zstd Parquet converted from the same verified native Arrow. Both B and D
pay common extraction/verification; D also pays conversion and full-schema
readback. The independent raw oracle is evaluation cost, displayed separately.
D is a downstream representation comparator, not an independent raw-to-Parquet
pipeline or a third independent scientific implementation.

Each round uses a fresh Python worker for each path. Q1/Q2/Q3 arrive in order;
no answers are precomputed inside a measured path. The parent receives identical
completion messages only after output publication and exact verification. Its
elapsed prefixes include interpreter startup once; worker termination time is
separate. Query costs include native children, receipt verification, reduction,
and outer answer checks. Separate inner verification times are already contained
in the total and must not be added again. One setup is added arithmetically to
each observed prefix; setup itself is not repeated. Acquisition is an additional
common term. No cache eviction, significance, p99, hard RSS cap, universal speedup,
or extrapolated crossover is claimed. A slower path passes if all scientific
and lifecycle gates pass.

The 10 ms process-tree sampler is adapted from the existing cohort benchmark:
sum worker and current descendants at each sample, excluding the monitor; it can
miss peaks and double-count shared pages. Missing samples are unavailable. Whole
workflow RSS uses the maximum of phase peaks, never their sum. Storage reports
logical bytes separately for raw inputs, minimum replay caches, metadata,
exports/receipts, and retained diagnostics.

The native 256 MiB budget is cooperative. Materialization uses legacy `all`/63;
fresh and saved queries both project `depths,alleles,strands`. MAPQ/BQ stay 20,
HG002 is explicit, mates count separately, missing qualities never pass. Saved
aggregates cannot undo filtering or answer unmeasured loci. Histograms and all
integer values are exact; no pandas or floating-point coercion is allowed.

The runner never builds or installs. CI builds an exact commit with one target,
pinned Rust and wheel-only Python dependencies, and checks the explicit binary
against its build digest and native metadata. The replay inventory detects byte
changes relative to its retained identity; unsigned coordinated rewrites are not
authenticated. Original receipt bytes are never rewritten for relocation.

Stop after acceptance or a precise blocker, with at most one justified correction
attempt. Preserve all failed attempts. No HG001 acquisition, refit, threshold
change, cohort expansion, or optimization search belongs to this protocol. The
[cohort no-go](../../docs/findings/bounded-cohort-reanalysis-2026-10-22/README.md)
and [HG001 practical-benefit failure](../threshold-transfer/CONTINUATION_RESULTS.md)
remain in force. This study does not establish clinical or neural-interface value,
release readiness, or outside-user adoption.
